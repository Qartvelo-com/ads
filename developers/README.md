# Qartvelo Ads Developers

Public developer documentation for Qartvelo Ads, published at **https://developers.qartvelo.com**.
Built with [Astro Starlight](https://starlight.astro.build).

```
developers/
├── astro.config.mjs            site config, sidebar, llms.txt plugin
├── src/content/docs/           the pages (Markdown / MDX), one folder per sidebar group
├── src/components/PageTitle.astro   "Copy page", "View as Markdown", "Ask AI" actions
├── src/pages/[...slug].md.ts   serves every page as /<slug>.md
├── public/openapi.yaml         OpenAPI 3.1 spec of the SDK REST API
├── public/skills/qartvelo-ads/SKILL.md   agent skill (Claude Code, Cursor, Copilot, AGENTS.md)
└── mcp/                        @qartvelo/ads-mcp, the MCP server for AI agents
```

## Develop

```sh
cd developers
npm ci
npm run dev       # http://localhost:4321
npm run build     # static site in dist/
```

Pages live in `src/content/docs`. Add new pages to the `sidebar` in `astro.config.mjs`. Keep facts in
sync with the SDK sources (`android/`, `react-native/`) and the backend API; when the SDK version
changes, update the version strings (search for `0.5.1`), `resources/changelog.md`, the skill and
`mcp/src/snippets.js`.

## AI features

- `/llms.txt`, `/llms-full.txt`, `/llms-small.txt` and per-section sets under `/_llms-txt/` are
  generated by `starlight-llms-txt` on every build.
- Every page is also served as Markdown at `/<slug>.md`.
- `public/openapi.yaml` is linted in CI with Redocly.
- `mcp/` is the MCP server. `cd mcp && npm ci && npm test` bundles the docs and runs its tests.

## Deploy

`.github/workflows/docs.yml` builds the site and tests the MCP server on every push and pull request.
On `main` it deploys to GitHub Pages when the repository variable `DOCS_PAGES_ENABLED` is `true`
(a manual run of the workflow on `main` always deploys):

1. Settings -> Pages -> Source: **GitHub Actions**.
2. Settings -> Secrets and variables -> Actions -> Variables: `DOCS_PAGES_ENABLED` = `true`.
3. DNS (Cloudflare): `CNAME developers -> qartvelo-com.github.io` (`public/CNAME` sets the custom domain).

The MCP server is published to npm as `@qartvelo/ads-mcp` by the Publish workflow together with the
SDK tags, when the `NPM_TOKEN` secret is set. To publish it between SDK releases, bump
`developers/mcp/package.json` and run the Publish workflow manually with **mcp_only**.
